# Shanel Crafts PH

A mobile-first, single-page showcase site for Shanel Crafts PH built with React, Vite, and GSAP.

## Run locally

Install dependencies and start the Vite development server:

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Before publishing

Replace the placeholder Facebook Messenger and Instagram URLs in `index.html` with the shop's actual page/profile URLs. Product images are kept in `assets/` and can be swapped without changing the layout.
